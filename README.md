## 🌍 Solar and Terrestrial Radiation (MTO225)

This repository contains project work for the **Solar and Terrestrial Radiation** course at Istanbul Technical University during the **2022–2023 Fall semester**.

### 📌 Project Description  
The project is based on real observational data obtained from the **Muğla Weather Observation Station (Station No: 17292)**. The dataset includes measurements related to atmospheric and solar radiation, which were analyzed to study radiation balance and related environmental parameters.

### 📊 Content  
- **Project Report (MTO PROJE.pdf):**  
  Contains detailed explanations, methodology, and solutions to the assigned research questions.  
- **MATLAB Code (mto.m):**  
  Includes the implementation used for calculations and analysis of radiation-related parameters.  
- **Dataset:**  
  Weather and radiation data from the Muğla station used throughout the project.

### ⚙️ Tools and Methods  
- MATLAB for numerical modeling and data analysis  
- Atmospheric and solar radiation calculations  
- Data interpretation and visualization
